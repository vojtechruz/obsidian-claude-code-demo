# Workshop: Obsidian + Claude Code

Demo vault fiktivní persony **Ondry Kratochvíla**, Java vývojáře z Prahy. Ukazuje, jak držet osobní život a práci v Obsidianu (PARA, deník, TaskNotes) a jak nad tím automatizovat rutinu pomocí Claude Code skills.

## Dokumentace

1. [[Jak funguje denik]] – k čemu je deník a jak funguje
2. [[Mapa vaultu]] – kde co je, PARA a konvence
3. [[Pluginy]] – co dělají a kde je uvidíš
4. [[Skills]] – přehled 13 skills, co čtou a píšou, jak se skládají
5. [[Scenare]] – prompty k vyzkoušení krok za krokem ⭐
6. [[Reset a reseni problemu]] – návrat do výchozího stavu, co jde na internet, potíže

## Doporučené pořadí na workshopu

1. Otevři vault v Obsidianu a projdi [[Denik]], [[2026-W40-plan]] a jeden projekt (třeba [[JOpenSpace 2026]]).
2. V terminálu v kořeni repa spusť `claude` a potvrď důvěru ke složce. Demo kalendář a skripty skills jsou povolené předem v `.claude/settings.json`, takže se na ně nebude ptát.
3. Scénáře 1, 3 a 4 z [[Scenare]]: souhrn týdne, plán týdne, zpracování závodu.
4. `git checkout -- . && git clean -fd` a zkus vlastní nápad.
