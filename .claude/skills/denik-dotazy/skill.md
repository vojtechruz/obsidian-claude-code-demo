# Denik query

Answers questions about the user's journal by searching `Denik/`. **Read-only** — this skill never writes or modifies notes.

## Vault layout (uses Folder Notes plugin)

```
Denik/
  Denik.md              <- MOC / rozcestník (generated by denik-souhrn)
  2026/
    2026.md                  <- yearly folder note for 2026
    2026-07/                 <- month folder (YYYY-MM)
      2026-07.md             <- monthly summary (folder note)
      2026-07-15.md          <- daily note (source of truth)
    Weekly/
      2026-W29.md            <- weekly summary
```

- **Daily notes:** `Denik/YYYY/YYYY-MM/YYYY-MM-DD.md` — the primary source
- **Weekly:** `Denik/YYYY/Weekly/YYYY-Www.md` (ISO week)
- **Monthly:** `Denik/YYYY/YYYY-MM/YYYY-MM.md`
- **Yearly:** `Denik/YYYY/YYYY.md`

Daily notes are **flat bullet lists** (`- text`), often without diacritics and with typos. Category headings (`## Práce`, …) appear only in the *summaries*, not in daily notes.

## Query types

1. **Temporal** — "kdy jsem naposledy…", "kdy jsem byl…"
   → find the **most recent** match; return date + the entry + how long ago.
2. **Frequency** — "kolikrát…", "jak často…"
   → count matches in the range; return count, the list of dates, and the rate.
3. **Fuzzy** — "cokoliv o…", "vše o…"
   → return all relevant entries, most recent first.

## Steps

1. **Parse the query** — determine type (temporal / frequency / fuzzy), *what* to search for, and *what time range*.
2. **Resolve the range with the Bash tool**, never by guessing (`date +%F`, `date -d "30 days ago" +%F`). State the resolved range back to the user if it isn't obvious.
3. **Search** — prefer Grep over reading many files:
   - `Grep` with `-i` over `Denik/` (add `glob` to narrow to a year/month).
   - Daily notes are the source of truth. Use summaries only to speed up a wide search or when the user explicitly asks about a period as a whole.
4. **Handle Czech spelling** — the notes are written quickly and inconsistently. Always search **both with and without diacritics**, and try word stems rather than full forms:
   - `lezení` → also `lezt`, `lezl`, `bouldering`, `stena`, `stěna`
   - `očkování` → also `ockovani`, `ockovan`
   - `běh` → also `beh`, `behat`, `běhat`, `bezel`
   - Match case-insensitively; some entries are ALL CAPS (`BEH S RADKEM 14 KM`).
   - Things with their own note are usually linked (`[[Wingspan]]`, `[[Lisabon 2026]]`, `[[Radek Simek|Radkem]]`) — search for the note name too, not only the free text.
5. **Answer** with dates in Czech format (`15. 7. 2026`) plus a relative hint (`před 3 týdny`). Quote the matching bullet so the user sees the original wording. If nothing matches, say so plainly — **never invent an entry**.

## Categories (in summaries)

`Práce` · `Lucie` · `Rodina a přátelé` · `Kondice a zdraví` · `Osobní růst` · `Radost` · `Domácnost` · `Administrativa` · `Memories`

Plus `AI shrnutí` and `Hlavní události` at the top of a summary.

For a category-scoped question ("co jsem dělal v práci", "co jsme podnikli s Lucií"), search within that section of the summaries — but verify against the daily notes, which hold the detail.

If the vault holds **older notes with a different category system** (e.g. `Byt`, `Sociální`, `Sport`…), treat them as equivalents when searching historical periods: `Byt` → Domácnost + Administrativa, `Sociální` → Rodina a přátelé, `Sport` → Kondice a zdraví.

## Time expressions

| Výraz | Význam |
|---|---|
| `poslední týden` | last 7 days |
| `poslední měsíc` | last 30 days |
| `poslední 3 měsíce` | last 90 days |
| `za poslední rok` | last 365 days |
| `v červnu` | whole of June (current year unless stated) |
| `v létě 2025` | June–August 2025 |
| `loni` | previous calendar year |
| `letos` / `v tomto roce` | current calendar year |

## Examples

**Q: Kdy jsem naposledy hrál Wingspan?**
```
18. 9. 2026 (před 13 dny)
- "deskovky u Novotnych - [[Wingspan]], Hana vyhrala o 2 body"
Letos celkem 6× (naposledy 18. 9., předtím 21. 8., 10. 7., …).
```

**Q: Kolikrát jsem byl lézt za poslední 3 měsíce?**
```
11× (~1× týdně; vynecháno 1.7. chalupa, 12.8. Dolomity, 16.9. den před přednáškou)
8.7. · 15.7. · 22.7. · 29.7. · 5.8. · 19.8. · 26.8. · 2.9. · 9.9. · 23.9. · 30.9.
Poslední: 30. 9. – "Bouldering, dal jsem 5C"
```

**Q: Co jsem dělal v Lisabonu?**
```
Duben 2026 — [[Lisabon 2026]] s Lucií (16.–20. 4.):
- 16.4. prilet, Alfama, vecer fado
- 17.4. Belem, pasteis de nata
- 18.4. Sintra, ranni beh podel reky
- 20.4. odlet, doma vecer
```

## Notes

- **Read-only.** If the user wants a summary note written, that's the `denik-souhrn` skill.
- Relative dates are computed against **today** — always get it from `date`, never assume.
- Prefer quoting the original bullet over paraphrasing; the user's own wording is the record.
- If a query spans many years, search year by year and report per-year counts.
